# Disk Covering Benchmark · 单位圆盘覆盖测评


用 n 个同样大小的圆盘覆盖整个单位圆盘，最小半径是多少？本项目用这个问题观察 AI 从寻找构型到严格证明的研究能力，并记录完成任务的时间与成本。

完整解题要求交付最优半径的最小多项式与有理根隔离区间、精确构型、整个圆盘的覆盖证明和不限制构型的全局最优性证明。

## 题目与测试记录

**[打开构型图目录 →](index.zh.html)**

按 n 浏览构型图，点击图片进入题目页：测试成绩、可复制的完整 Prompt、标准 SHA256 与核对框都在同一页。中英文可切换；目录列出 n=11—29，每页12题。未发布标准指纹的题目显示“未知”。

已发布 n = 11、12、14、16、19、22、25、26、27 的参考指纹，均已核对精确根隔离与整数舍入，并独立重算哈希。指纹匹配仅核对答案数据，不验证提交者的证明。公开提交尚未开放；现有分数仍属历史演示成绩，正式测试合同尚未冻结。

评分时限：每道 n≤30 的题目限12小时（43200秒）；超过时限仍无符合该题验收要求的有效结果，计0分，超时后完成仍计0分。未测试不计作0分。

## 共用工具

所有题目共用一套工具。先阅读[测试指南](guide.zh.html)，了解计时、评分、验收以及从答案到哈希的完整流程。

**[下载测试工具与资料（ZIP）](https://github.com/pikaaa345/disk-covering-benchmark/archive/refs/heads/main.zip)**

一次下载包含：答案核对脚本与中英文编码协议、计分脚本、自检程序、报告生成 Prompt、各题题面和使用说明；也包含已公开记录的限定摘要。网站源码与开发历史在私有仓库维护。无需分别下载。

解压后进入项目文件夹，按测试指南运行脚本，仅需 Python 3.9+ 和标准库。系数按幂次从低到高排列，半径保留20位小数；核对脚本统一编码并生成 SHA256。哈希匹配只核对答案数据，不验证证明或耗时真实性。

**AI 入口：** [操作说明](agents.zh.html) · [机器可读索引](benchmark.json)。索引提供各题题面、记录与协议的位置，无须遍历网页菜单。

## 发布与许可

公开仓库提供可下载的工具与测试材料。网站源码及开发历史在私有仓库维护，网站只发布已核定的页面。公开下载材料仍有自己的 Git 修改历史。

工具采用 [MIT 许可证](LICENSE.txt)。仓库不包含闭源求解算法或精确标准答案。

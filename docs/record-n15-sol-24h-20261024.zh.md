### 任务要求与判定标准

设闭单位圆盘为 $D$，十五圆心组成有序组 $C$，覆盖半径定义为

$$
R_D(C)=\max_{x\in D}\min_{1\le i\le15}\|x-c_i\|_2,
\qquad r_D(15)=\inf_C R_D(C).
$$

覆盖圆盘可以重叠、超出单位圆盘，圆心不预先限制在单位圆盘内。题目要求同时完成以下内容：

| 要求 | 必须达到的标准 |
| --- | --- |
| 半径最小多项式 | 列出半径本身在有理数域上最小多项式的全部规范化整数系数，并证明不可约 |
| 根的确定 | 给出具体有理隔离区间，证明端点非根、区间内恰有一个实根，并将该根与最优半径对应 |
| 精确构型 | 提交确定的十五圆心有序组，有限代数数据须有唯一性证明 |
| 连续覆盖 | 证明整个闭单位圆盘被覆盖；有限化检查必须有充分性证明且全部完成 |
| 全局下界 | 对所有十五圆心构型成立，不得未经证明预设对称性、接触结构或排除退化情形 |
| 计算材料 | 提交实际使用的代码、输入、证书、环境及结果，并解释计算为何推出数学结论 |

只有存在性或代数性、尚未完成的算法、数值候选、采样或图像检查都不算完成。即使一个几何根被精确定义，若没有提交半径本身的最小多项式及相应证明，仍不满足本题。完整题面见 [n=15题目页](n15.zh.html?lang=zh)；本节是验收要求摘要，不冒充原始用户消息的逐字导出。

### 路线变化、问题与失败原因

研究前段的主要工作是理解和复核几何成果，随后重点转向补足代数交付。随着计算推进，精确构型和几何根的对应逐步明确，但这与“显式得到半径的最小多项式”仍是两项不同任务。工作量的增加没有自动消除两者之间的缺口。

后期进行了多轮计算模型调整、结果检验与工具层面的优化。部分计算受到规模、内存和程序稳定性的限制；保存了中间成果，却未形成能够完成有理数域证明的最终代数输出。**最后的直接代数计算未产生有效结果，选定输出文件为空；保存进度或备份检查通过不等于求解完成。**

数值精度提高可以帮助寻找关系，也可以暴露某个模型是否与目标几何对象一致，但它不能证明整数关系恰好成立，更不能单独证明不可约性。已有精确关系或多变量代数定义同样不能替代题目指定的一元最小多项式。

失败的直接原因是最终交付缺项，而不是“没有做过验证”。现有记录支持已有几何和局部代数进展，却不足以确认最小多项式的次数、全部系数和必需证明，也不能据此断言增加内存、磁盘或运行时间就必定能完成。

# n=15 · gpt-6.2 astra/max（12h）测试报告

[返回 n=15](n15.zh.html?lang=zh) · [测试记录目录](records.zh.html)

本次测试要求求出十五个等半径闭圆盘覆盖单位闭圆盘的精确最小半径。模型在十二小时时限内交付了证明包，提交答案的指纹与公开参考值一致。网站登记**自报成绩 261 分**。

### 证明来源与本次模型工作

题目来自 n=15 英文测评 Prompt。用户允许使用当前对话工作区的数据，并禁止在求解中使用本地技能或既有研究资料。几何证明、代数数据和验证程序由本次运行产生。参考指纹在原测试结束后的归档阶段核对。

### 任务要求与判定标准

记 $D$ 为单位闭圆盘，$C=(c_1,\ldots,c_{15})$ 为有序圆心组。题目要求求出下列覆盖半径的下确界。

$$
R_D(C)=\max_{x\in D}\min_{1\le i\le15}\|x-c_i\|_2,
\qquad r_D(15)=\inf_C R_D(C).
$$

| 要求 | 本次测试的判定标准 |
| --- | --- |
| 半径最小多项式 | 列出首项系数为正的本原整数多项式全部系数，并证明有理不可约 |
| 实根识别 | 给出有理隔离端点，证明区间内实根唯一，并将该根识别为最优半径 |
| 精确构型 | 用具有唯一性的有限代数数据指定十五个有序圆心 |
| 连续覆盖 | 证明整个单位闭圆盘均被覆盖，并证明所用有限化归充分 |
| 全局下界 | 从任意圆心组出发证明下界，并处理相关退化情形 |
| 计算材料 | 提供实际代码、输入、证书、环境和验证结果，说明它们在证明中的作用 |

完整 Prompt 见 [n=15 题目页](n15.zh.html?lang=zh)。

### 主要研究阶段

| 阶段 | 工作 | 实际结果 |
| --- | --- | --- |
| 构型确定 | 寻找候选，并用孤立代数方程组指定圆心 | 得到十五个有序圆心的精确数据 |
| 覆盖与下界 | 验证整盘覆盖，并检验所有可能严格改进候选的情形 | 得到可行覆盖及计算机辅助的全局下界 |
| 最小多项式 | 恢复整数系数，核验不可约性及有理实根隔离 | 得到 2869 次多项式的全部 2870 个系数 |
| 实根识别 | 用代数证书和区间证书联系一元根与精确构型 | 在 5186 个素数上取得精确同余，并用范数界证得有理恒等式 |
| 提交复核 | 从交付目录重放几何与代数证书 | 保存实际通过的重放记录 |

### 路线变化与主要困难

几何证明先于一元多项式完整系数完成。早期系数重构没有收敛，运行修正了一次因子的归一化并重新恢复系数。随后分别核验不可约性、隔离实根及实根与几何系统的等同关系。上述计时记录整次求解的用时。

| 最小多项式 | 完整系数及四组有限域分解证书 | 本原性、首项符号和有理不可约性 |
| 实根隔离与识别 | 整数根计数、区间和同余证书 | 识别隔离实根与候选构型半径 |
| 计算材料 | 代码、输入、证书、环境及运行日志 | 原始交付记录完整重放 |

# 问题背景

单位圆盘是平面上到原点距离不超过1的所有点。我们使用 n 个半径相同的闭圆盘覆盖它，允许重叠和超出边界，寻找最小的公共半径。覆盖的是包括边界在内的整个区域。

Erich Friedman 的 [Circles Covering Circles](https://erich-friedman.github.io/packing/circovcir/) 按 n 展示已知构型，并分别标注构型发现者和部分最优性证明。该页采用“固定小圆半径为1、尽量覆盖更大的圆”的尺度；这里采用“被覆盖圆半径为1、尽量减小覆盖圆半径”的尺度，两者通过整体缩放互换。发现好的构型与证明全局最优是不同工作。

这个问题连接了几个研究环节：几何和连续优化寻找候选，组合分类与严格剪枝排除更优构型，算法设计压缩计算，精确代数把半径指定为唯一实根，最终核验将计算结果连接到数学命题。因此它可以同时展示模型的研究选择、计算效率和证据质量。

有的 n 可能更适合特定结构或低次代数表达，难度并不严格随 n 增加。项目不把整个题库统一宣称为尚未解决的公开问题，也不将已有候选表格视作完整证明。每题的状态需要单独记录。

要求最小多项式是为了提供精确、紧凑、可规范编码的答案数据。它不能替代证明；构造出正确候选的最小多项式，仍可能没有完成覆盖性和全局下界。本项目将数学交付和轻量指纹核对分别说明。

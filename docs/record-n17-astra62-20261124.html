Unit Disk Covering Benchmark · n = 17

n=17 · gpt-6.2-astra/max test report

The gpt-6.2-astra/max run **determined the optimal radius** and submitted 17 exact centers, a proof of coverage of the entire closed unit disk, and a proof of global optimality. The run **did not obtain the minimal polynomial** within the 12-hour limit. Its actual degree and full list of integer coefficients remained unresolved. The benchmark scored the submission **0 (Incomplete)**.

### Proof sources and the model's contribution

The run used the public [Cover17 certificate](https://github.com/VonEquinox/DiskCoveringSolve/tree/089584973f41e6374ce110f6e5b5ee456df19352/cover17) for the global lower bound. It reported replaying all seven verification stages and submitted a separate continuous coverage check for its configuration.

### Task and acceptance standard

The task requires the optimal radius’s normalized irreducible minimal polynomial with all integer coefficients, a rational root-isolating interval, exact centers, coverage of the closed unit disk, and global optimality over arbitrary 17-center configurations.

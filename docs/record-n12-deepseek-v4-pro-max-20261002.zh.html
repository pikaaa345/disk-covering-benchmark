### 验证、错误与验收

**决定性反例：有严格更好的可行覆盖。** 本审核从数学项目的一个已保存十二圆记录提取十二个具体有理圆心，选择有理半径 $\beta$，重新构造所有必要的连续覆盖检查点，用 Python `Fraction` 精确分数和二次根式的有符号比较核验整个闭单位圆盘的覆盖。共检查 293 个去重后的点、2,071 次精确距离比较，结果为 `ACCEPT`。检查点来自完整的 Voronoi 极值归约，包含内部三圆心外心、所有两圆心垂直平分线与单位圆的交点、圆周光滑段极值和退化处理，不是有限采样。

随后精确计算得到 $P(\beta)<0$。原提交已经正确证明 $P$ 严格递增，且 $P(\alpha)=0$，所以

$$r_D(12)\le\beta<\alpha.$$

这直接否定“所提交的根就是最优半径”，也否定所需的 $\forall C:R_D(C)\ge\alpha$。该结论不依赖原数学项目的全局分类或最优性声明，只需要本次明确给出的有理覆盖及精确检查；没有在本报告中认证真正全局最优值。

**原提交另有三个证据问题。** §5.2 从 $m\,2\arcsin r\ge2\pi$ 只能推出 $\arcsin r\ge\pi/m$；当 $m\ge9$ 时，不能推出所写的 $\pi/9$ 下界。只有另证 $m\le9$ 才能使用该加强，而原题允许十二个边界圆盘。否定这一证明不等于否定其下界数值本身。

§5.3 的有限需求点、有限候选圆心 LP 不自动成为整个连续圆盘的分数覆盖证书。未覆盖的连续位置和中心限制的方向均须处理；小于十二的有限网格目标值不能证明连续问题的整体性间隙，更不能证明所有 LP/dual 路线无效。

§4.2 的高精度小残差和正差距缺少严格包围保证。§4.3 即使有效，也只处理放宽后的半径，不能推出精确半径的覆盖；其 `sup_sq` 中负差值统一向上舍入后再取绝对值可能缩小距离上界，中心十进制端点也没有完整的精确包围证明。因此没有将该输出直接认定为严格证书。

**审核与保存范围。** 已读取最终提交、直接支撑程序、原模型配置与usage，并实际执行上述精确更优覆盖检查。没有重新运行整个原优化、Newton、PSLQ、LP或C分支界。原报告、代码、输出、源快照、反例有理输入、核验器与结果都保留。数学项目原记录的自审与条件范围也保留，没有自动转换成独立同行审稿或无条件最优定理。

### 验证、错误与验收

**决定性反例：有严格更好的可行覆盖。** 本审核从数学项目的一个已保存十二圆记录提取十二个具体有理圆心，选择有理半径 $\beta$，重新构造所有必要的连续覆盖检查点，用 Python `Fraction` 精确分数和二次根式的有符号比较核验整个闭单位圆盘的覆盖。共检查 293 个去重后的点、2,071 次精确距离比较，结果为 `ACCEPT`。检查点来自完整的 Voronoi 极值归约，包含内部三圆心外心、所有两圆心垂直平分线与单位圆的交点、圆周光滑段极值和退化处理，不是有限采样。

随后精确计算得到 $P(\beta)<0$。原提交已经正确证明 $P$ 严格递增，且 $P(\alpha)=0$，所以

$$r_D(12)\le\beta<\alpha.$$

这直接否定“所提交的根就是最优半径”，也否定所需的 $\forall C:R_D(C)\ge\alpha$。该结论不依赖原数学项目的全局分类或最优性声明，只需要本次明确给出的有理覆盖及精确检查；没有在本报告中认证真正全局最优值。

**原提交另有三个证据问题。** §5.2 从 $m\,2\arcsin r\ge2\pi$ 只能推出 $\arcsin r\ge\pi/m$；当 $m\ge9$ 时，不能推出所写的 $\pi/9$ 下界。只有另证 $m\le9$ 才能使用该加强，而原题允许十二个边界圆盘。否定这一证明不等于否定其下界数值本身。

§5.3 的有限需求点、有限候选圆心 LP 不自动成为整个连续圆盘的分数覆盖证书。未覆盖的连续位置和中心限制的方向均须处理；小于十二的有限网格目标值不能证明连续问题的整体性间隙，更不能证明所有 LP/dual 路线无效。

§4.2 的高精度小残差和正差距缺少严格包围保证。§4.3 即使有效，也只处理放宽后的半径，不能推出精确半径的覆盖；其 `sup_sq` 中负差值统一向上舍入后再取绝对值可能缩小距离上界，中心十进制端点也没有完整的精确包围证明。因此没有将该输出直接认定为严格证书。

# n=15 · gpt-6.1 sol/max (24h) test report

The task required every coefficient of the radius minimal polynomial, an exact configuration, continuous coverage and a global lower bound for arbitrary configurations. **No submission meeting all requirements was obtained. The score is 0.**

### Task and acceptance standard

For the closed unit disk $D$ and an ordered tuple $C$ of fifteen centers, define

$$
R_D(C)=\max_{x\in D}\min_{1\le i\le15}\|x-c_i\|_2,
\qquad r_D(15)=\inf_C R_D(C).
$$

Covering disks may overlap and extend outside the unit disk; centers are not initially restricted to it. All the following requirements must hold together:

| Requirement | Required standard |
| --- | --- |
| Radius minimal polynomial | Every coefficient of its normalized primitive integer representation, with positive leading coefficient and an irreducibility proof over the rationals |
| Root identification | Explicit rational isolation endpoints, nonzero endpoint values, exactly one real root in the interval and identification with the optimal radius |
| Exact configuration | Fifteen ordered centers specified by finite algebraic data with uniqueness proved |
| Continuous coverage | Coverage of the entire closed unit disk; any finite reduction must be sufficient and every necessary check completed |
| Global lower bound | Valid for arbitrary configurations, without unjustified symmetry or contact assumptions and with relevant degeneracies handled |
| Computational materials | Actual code, inputs, certificates, environment and results, with an explanation of their mathematical implications |

Existence, algebraicity, an unfinished algorithm, a numerical candidate, sampling or an image is insufficient. Precisely defining a geometric root does not replace the minimal polynomial of the radius itself. The full prompt is on the [n=15 problem page](n15.html?lang=en). This section summarizes the acceptance conditions; it is not represented as a verbatim export of the original user message.

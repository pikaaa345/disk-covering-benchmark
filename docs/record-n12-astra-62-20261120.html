# n=12 · gpt-6.2 astra/max test report

[Back to n=12](n12.html?lang=en) · [Test records](records.html)

The run asked for the exact minimum radius for covering the closed unit disk with twelve congruent disks. The model delivered a computer-assisted proof package within the twelve-hour limit. Its answer fingerprint matched the published reference. The historical efficiency score is **671**.

### Proof sources and the model's contribution

The model reused the published configuration and geometric certificates of VonEquinox at commit `089584973f41e6374ce110f6e5b5ee456df19352` and replayed all eight verification modules. It derived the minimal polynomial and verified irreducibility, root isolation, and the triangulation counts using separate exact calculations. [Published geometry package](https://github.com/VonEquinox/DiskCoveringSolve/tree/089584973f41e6374ce110f6e5b5ee456df19352/cover12)

### Task and acceptance standard

The problem required a primitive integer minimal polynomial for the optimal radius, an isolating interval and a proof identifying its root, exact ordered centers, continuous coverage, and a lower bound for arbitrary center tuples. A computational proof also had to supply the code, certificates and replay results. The test allowed online sources and this run's working directory. The user excluded existing local research materials and skills. [Full test prompt](n12.html?lang=en)
